# Featureflip

Feature flag platform with automated dead-flag cleanup (via a GitHub Action), flat pricing, and API-first, agent-native surfaces. Exposes a Management REST API and a high-performance Evaluation API, both with public OpenAPI contracts, plus SDKs for many languages.

## APIs

- **Management API** — Programmatic access to Featureflip — projects, environments, feature flags, variations, targeting, segments, and SDK keys. Bearer-token auth (ffp_ personal / ffs_ service tokens). (`https://api.featureflip.io`)
- **Evaluation API** — High-performance feature flag evaluation service for SDKs, with client and SDK endpoints for evaluation, identify, streaming, flags, and events. (`https://eval.featureflip.io`)
- **MCP Server (local)** — Documentation for the @featureflip/mcp server, a local stdio process run via npx that calls the Management API on your behalf using a bearer token. (`https://featureflip.io/docs/integrations/mcp/`)

> Two REST APIs with public OpenAPI 3.0.4 contracts confirmed live (Management at api.featureflip.io, Evaluation at eval.featureflip.io). A Spectral ruleset is published at https://featureflip.io/openapi/spectral.yaml and a full-text llms variant at https://featureflip.io/llms-full.txt. The MCP server (@featureflip/mcp) is LOCAL only — it runs over stdio via npx, so it is NOT cataloged as an MCPServer property; no hosted/public MCP endpoint exists.
